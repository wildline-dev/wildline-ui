{% comment %} The Backlinks card (#17): the records that link to the one shown, such as the reports a contact made. Include it with card, a dict the view builds (see wildline_ui/cards.py). Which fields each item shows (a summary, or all of them) is the view's choice: it lists them in fields. Each item is an inset box, like the Object card's related record, with an arrow to its page. Load its CSS with {% object_card_assets %}. To add header buttons, extend it and fill the actions block. Records with no page of their own, such as a contact's phone numbers, can be changed here instead (#25). With card.edit, a pencil in the header shows a pencil on each item that has an edit, and a full-width button under them for the card's add. Each opens its form in place, with all its fields; saving collapses it again. Like the Object card, it needs no JavaScript: the pencils and the add button are checkboxes. {% endcomment %}{% load wildline_ui %}{% with edit=card.edit add=card.add %}
