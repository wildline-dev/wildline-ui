{% comment %} The Backlinks card (#17): the records that link to the one shown, such as the reports a contact made. Include it with card, a dict the view builds (see wildline_ui/cards.py). Which fields each item shows (a summary, or all of them) is the view's choice: it lists them in fields. Each item is an inset box, like the Object card's related record, with an arrow to its page. Load its CSS with {% object_card_assets %}. To add header buttons, extend it and fill the actions block. Records with no page of their own, such as a contact's phone numbers, can be changed here instead (#25): an item's edit puts a pencil on it that turns it into a form, with an optional Remove, and the card's add puts a + in the header that opens a form for a new one. Like the Object card, it needs no JavaScript: the pencil and the + are checkboxes. {% endcomment %}{% load wildline_ui %}{% with add=card.add %}
